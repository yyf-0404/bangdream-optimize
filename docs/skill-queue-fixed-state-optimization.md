# 非连锁排队第二轮优化（2026-09-17）

本轮基线是[上一轮窗口缓存优化](skill-queue-window-optimization.md)后的正确排队实现，不是最初约 475 秒的版本。保持贡献剪枝、候选范围、整数评分、推荐顺序及触发概率定义不变。

另补充了[三曲均有非连锁排队的压力测试](skill-queue-three-song-benchmark.md)：8 SP / 66 SP / 59 SP，最高分 82.125 → 68.957 秒、平均 PT 133.952 → 114.295 秒，前后结果和搜索计数一致。

## 实现

1. 条件窗口缓存同时记录各技能位是否对所有合法前驱时长都相同。此类位置只读一次窗口、计算一次增量，直接填入五个前驱位置；全队时长相同时也适用。会随前驱变化的位置保留原条件窗口和去重逻辑；非标准时长仍走原验证/调度路径。每张缓存谱面多 102 个布尔值，无新增按候选扩张的缓存。
2. 五张卡的“子集 + 末卡”精确动态规划展开为固定状态，按目标状态汇集前驱，避免每次评分的位扫描和反复覆盖状态。以 `i64` 同时编码整数分数与五张卡及队长的字典序，比较一次即可保持原同分规则；负增量也支持。不改变搜索的排列集合，不近似浮点或跳过取整。

原生微基准仅顺序 DP：100 万次、256 组含负增量/同分的矩阵，原实现约 751–763 ms，固定状态约 90–96 ms。这只是局部内核数据；完整计算收益以下表为准。
