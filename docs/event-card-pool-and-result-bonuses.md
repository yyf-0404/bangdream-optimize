# 活动可用卡池与结果加成（2026-09-17）

## 已确认规则

- 最高得分、最大平均 PT 共用档案设置 `eventAvailableCardsOnly`，默认关闭。指定队伍、控分不使用该限制。
- 开启后只保留当前服务器 `releasedAt < event.endAt` 的已持有卡牌，包含活动中途发布的卡，不按当前时间或卡库筛选的未来七天窗口截断。
- 活动结束时间、卡牌发布时间均只读当前服，不回退其他服。卡牌没有本服发布时间则排除。
- 正式活动的起止时间优先使用随 manifest 更新的活动列表，列表缺少某服日期时才使用详情或档案缓存中该服的日期；旧缓存不能覆盖列表中已有的新日期。显示和计算使用同一份合并后的活动快照，兼容数组与已按服务器选取的单值时间。
- 自定义卡没有正式发布时间，能按结束时间筛选时不参与。自定义活动或缺少本服结束时间时，自动回退到全部已持有卡牌及已启用的自定义卡，不阻止计算、不自动关闭开关；以后有结束时间时恢复筛选。
- 只筛选提交给计算运行时的副本，不删持有记录、不修改档案中的自定义卡启用状态。网页 WASM 和桌面端经过同一前端计算入口。
- 开关参与结果缓存键；命中时还核对当前卡池、结束时间及缺失时间回退状态，避免误用另一种卡池的结果。诊断中的 `player` 是实际计算卡池，`sourcePlayer` 保存原档案用于变化检测，`cardAvailability` 记录判定依据。

## 结果展示

- 道具选择沿用原图片和布局，直接显示各组选中道具的加成；杂志标明对应演出、技巧或形象。
- 道具等级及服务器来自计算快照；通用道具保留海螺包、咖啡取较高值的规则。
- 角色加成默认折叠，按结果队伍去重收集角色，兼容自定义卡。
- 按用户最新要求，展开后只显示每位角色演出、技巧、形象三项合计（潜能加角色任务），不显示六个分项。
- 历史结果使用诊断快照，避免读取后来改动的养成等级。

## 验证

- 前端全量 162 项测试通过，覆盖日期边界、服务器不回退、未知时间使用全卡池（保留自定义卡）、已知时间的空卡池、两种自动搜索提交副本、缓存区分和档案不变检查，以及旧缓存遮蔽新日期与单值时间格式的回归。
- 结束时间修复核对本地 342 个活动：列表中已有结束时间的日服 341、国际服 314、台服 325、国服 322、韩服 169 条均正确传递至卡池判断。浏览器复现活动 321 加载旧详情后的缺失提示，修复后显示正常，预览档案符合条件 13 张。
- 验证道具百分比单位、角色合计、结果结构兼容和历史快照服务器。
- 浏览器验证两种自动目标显示开关、指定队伍隐藏。缺失本服结束时间已按后续要求改为自动使用全卡池，测试覆盖结束时间缺失和恢复时的缓存失效。
- 使用已有三曲最高分结果验证道具与五位角色合计；390 像素视口下图片、折叠入口和合计没有横向溢出，已恢复默认视口。
- 本次未改动 Rust 评分或搜索实现；未重新打包桌面客户端。
