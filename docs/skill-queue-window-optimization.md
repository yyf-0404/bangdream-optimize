# 非连锁排队评分优化（2026-09-17）

本轮优化的是已经正确处理非连锁排队的实现，与旧版独立叠加重叠窗口的算法不同。评分、贡献剪枝、候选门槛、搜索范围与触发概率定义不变。

后续又完成了[固定状态与前驱无关窗口优化](skill-queue-fixed-state-optimization.md)。本页保留第一轮的二进制与计时；第二轮相对本页优化版重新交错复测，不能混用不同批次的耗时计算收益。

## 改动

- 条件技能窗口只依赖初始化后的谱面、当前技能时长和前驱时长。对 17 种支持时长预计算音符范围与倍率段范围，候选直接查询。每张有排队风险、含六个技能点的谱面约增加 54 KiB 原生缓存；谱面克隆共享缓存，重新初始化时重建。未命中缓存的时长保留原路径，渐强技能仍执行原有时长约束。
- 无技能基础分与技能增量复用相同倍率段，保留逐次整数取整；渐强技能复用既有 AVX2 增量内核，保留倍率逐音符递推。提供无 AVX2 的可移植路径，Fever / 评分模式不匹配仍使用原精确评分。
- 同一队伍中相同技能的矩阵列直接复用；不同前驱得到相同窗口时复用已计算增量。候选循环中的临时 Vec 改成固定小数组。
- 保留“已用卡牌集合 + 最后一张卡”的精确动态规划，将路径压成 15 位整数。按同样的字典序处理同分，保持技能顺序和队长选择不变。

## 同条件原生完整计算

输入为冻结的 1,456 卡新档案、国服活动 323、**8 SP / 395 SP / 772 EX**；第一首有非连锁排队，其余两首没有。最高分强制 StrictExact，平均 PT 使用完整分带搜索，不自动切换随机桶。

## 结果与正确性

- 新旧完整业务结果逐项一致：三队、道具、队长、推荐顺序、最优触发顺序、概率、各曲分数和排队提示均相同。
- 最高分仍为 10,693,326；平均 PT 仍为 `721875418517 / 1073741824`。
- 最高分原始候选 8,087,204、实际评分 9,657,167、最佳池最终候选 34,697；平均 PT 原始候选 9,469,248、实际评分 11,696,180、保留候选合计 92,371。前后候选数及二、三队搜索计数完全相同，提速没有依赖减少搜索范围。
- 无排队的原 186 SP / 395 SP / 772 EX 输入也通过完整业务结果和搜索计数对照。优化后本轮核心耗时：最高分 32.602 秒，平均 PT 39.138 秒；跨批次硬件运行状态有波动，不以这些单轮时间评价小幅涨跌。
- Core / Data / Service 有效测试 233 项通过；原有可选测试跳过。新增验证缓存重建、合法/非法时长、手动/自动/Fever/渐强/重复技能，以及紧凑路径的同分处理；矩阵逐顺序和队长对照完整调度，128 组含负增量和大量同分的矩阵逐项穷举最优值与顺序。
- 离线全谱面对照：解析 3431 张谱面，559 组非连锁配置与 335,400 次完整时间轴评分一致；59 组连锁配置仍不进入快速路径，异常技能点数量的谱面单列排除。
- WASM Release 和网页绑定已重建；Node 实际加载网页 WASM，以完整结果中的 15 张卡重跑三曲精准搜索，最高分、三队、道具、推荐/触发顺序、概率和排队提示均与原生结果一致。这是跨后端正确性检查，不是完整 1,456 卡档案的 WASM 性能基准。
