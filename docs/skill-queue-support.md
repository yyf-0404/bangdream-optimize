# 技能排队支持

## 计算范围

无排队沿用原来的整数增量矩阵和排序快速路径。若最长候选技能的调度时间线不存在连续两次延后触发，则所有更短时长组合也不会连锁：当前技能窗口只需知道前一技能的时长。

单次排队按 `位置 × 前驱卡 × 当前卡` 预计算整数增量，保留音符基础分与技能倍率的取整。最高得分使用 `已用卡集合 × 最后一张卡` 的 DP，最后把第五张卡与队长配对计算第六次技能。平均 PT 将同一条件增量用于触发顺序评分，仍使用 96 种可达排列、总权重 1024 的概率模型；平均分数上界直接求加权和，无需构造各摆放方案的直方图。

指定队伍固定五个摆放位置和第三位队长，穷举 120 个触发排列，再按其中 96 个非零权重排列构造概率分布。每个排列均运行完整排队调度，支持连锁，不参加编队候选剪枝。

## 保留贡献剪枝

条件 Meta 覆盖全部支持的前驱技能时长，并按时长、倍率、递增类型缓存。用于枚举上界的是条件窗口最大值，不能直接拿它证明卡牌支配。

单次排队替换卡牌 A/B 时，贡献比较检查五种普通位置及五种队长位置：

- 被替换卡自身在相同前驱条件下的差值。
- 时长改变对下一技能窗口的影响，使用同一个后继技能在两种前驱时长下的差值。
- 队长在第六次复唱；若队长恰好第五次触发，处理它作为自身前驱的情况。
- 综合力改变对其余技能和基础分的影响。

所有条件下的贡献下界取最小值，并在队友综合力区间两端检查。新增排队支配边扣除综合力、音符基础分与技能倍率取整误差的保守上界。无法证明替换安全时保留候选。相同技能时长和类型、综合力与倍率均不差的替换仍可走逐点单调的硬支配路径。

## 连锁状态与结果提示

2026-09-17 接入实际判定区间状态表。原始状态由完整调度器生成，逐层从后向前合并：只有每种后续时长的判定区间、下一层状态类别都相同，才视为等价。不能只按当前音符区间合并。手动保留整数帧调度；Auto 保留原先的时间包络语义，不改成手动调度。两者的相同时刻判定顺序、递增加分和整数取整均保持不变。

连锁最高分使用 `已用卡集合 × 等价状态` 求最大值，第六次只重复所选队长；平均 PT 继续保留全部排列得分和真实权重。无排队使用原独立矩阵，非连锁使用原前驱矩阵和固定状态 DP；三种路径共享判定区间的构造语义。

连锁贡献剪枝同时推进替换前后的两个状态，每步选择同一个后续技能。进入相同后续等价类后，普通替换的时间差可以停止传播；队长第六次复唱仍需再次替换。不同综合力对全部基础分和技能分的影响、取整误差仍计入下界。枚举、道具与剩余队伍的上界改用全部可达状态的技能 Meta 最大值，避免一阶条件窗口低估连锁。

六技能点及标准离散时长的自动编队现在显示“已计入技能排队”，不再因连锁本身警告非最优。超出状态表覆盖的导入时长等情况仍保留保守警告；历史结果中已有的警告不会被前端自动清除。判断使用整个候选池，不能只检查最终队伍。

指定队伍不进行编队搜索，连锁也只显示“已计入技能排队”。普通排队提示与连锁警告复用同一个结果入口。旧历史结果只有 `skillQueueRisk` 时提示重新计算，不把旧的独立窗口相加结果解释成已修正的结果。

## 其他计算路径与已确认边界

- 巡回候选枚举、道具组合和剩余队伍的评分上界使用全部可达窗口的最大值，覆盖非连锁与连锁。它们是保守上界，不作为最终得分。
- 三队互斥、位图/AVX2 冲突检查和兼容队伍上界不依赖技能时间线，继续使用修正后的候选分数或加权平均分数。平均 PT 的 18,500 分搜索带来自 PT 取整公式，排队不改变该关系。
- 推荐摆放、最高分触发概率和平均 PT 都使用排队后的各顺序得分；96 种可达排列及其权重不因排队而改变。达到同一最高分的所有顺序合并计入概率。
- 单曲自动搜索和多人协力已有保守回退：风险谱面跳过不适用的贡献剪枝及部分独立窗口上界，使用全窗口乐观上界或完整时间线评分。多人协力保留自己的触发概率模型。这部分未把巡回的新剪枝优化全部移植过去，可能更慢。
- 分数区间找队仍跳过存在排队或技能尾部风险的谱面/技能时长组合。2026-09-17 用户确认允许保留跳过行为；这条路径不计入“已支持非连锁排队”的范围，可能不返回被跳过组合中的可用队伍。
- 旧结果需要重算；全谱面差分检查验证了评分，小型三队穷举验证了剪枝样本。2026-09-17 已优化非连锁窗口构造和整数评分：1,456 卡档案、8 SP / 395 SP / 772 EX，关闭详细诊断的同条件原生对照为最高分 474.858 → 50.855 秒、平均 PT 467.192 → 64.463 秒，业务结果和候选/搜索计数完全一致。详见 [窗口复用优化](skill-queue-window-optimization.md)。历史原 186 SP 三曲无排队，不能与此输入直接比较；此前含额外诊断的计时保留于 [基线复核](skill-queue-performance.md)。尚未做同条件 WASM 整轮性能测试。

## 验证

第二轮固定状态优化记录于 [后续优化对照](skill-queue-fixed-state-optimization.md)：相对窗口优化版重新交错各测两轮，最高分/平均 PT 总耗时均值分别减少 8.8% / 7.6%。全谱面验证已扩展到同分时的最优顺序和队长，运行路径与上述支持边界保持一致。

- 条件整数矩阵与完整调度逐项对照：手动和 Auto、不同技能时长、递增倍率、所有队长位置、整数边界及队长连续复唱。
- 排队贡献支配边逐一对照全部触发排列和队长位置；包含低倍率换高综合力的有效贡献剪枝。
- 小型三队完整搜索：不剪枝 7,865 个候选，生产剪枝保留 6,578 个，最优总分均为 391,226；接近最优分的 incumbent 剪枝仍保留同一最优值。这是正确性样本，不是大型档案性能基准。
- 2026-09-16 下载的完整目录共 3,431 张谱面；786 SPECIAL 含异常技能点数量，单独排除。最新离线对照包含手动/Auto、三组时长：559 组非连锁及 59 组连锁配置，共 370,800 个完整调度排列/队长组合。最高分均一致；非连锁校验字典序同分选择，连锁保留原种子同分规则并验证所选顺序确实达到最高分。
- 实际状态压缩、剪枝与整轮性能见 [状态表优化](skill-queue-state-optimization.md)。离线单次评分耗时不能代表编队总耗时。
- 窗口优化后的回归：Core/Data/Service 共 233 项有效测试通过，原有可选测试跳过；此前网页端 139 项测试及普通排队、自动编队连锁、指定队伍连锁三种结果提示已验收。本轮重新构建 WASM Release 与网页绑定，并实际加载 WASM 用 15 张结果卡重跑三曲，分数、队伍、顺序、概率和排队提示与原生结果一致。

```powershell
cargo run --offline -j 1 -p bangdream-optimize-data --release --example check_skill_queue -- tmp/skill-queue-catalog-audit/data tmp/skill-queue-catalog-audit/score-check.json
```
