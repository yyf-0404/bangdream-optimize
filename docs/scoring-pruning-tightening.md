# 原生算术迁移后的剪枝收紧

日期：2026-09-20。本轮首先比较原生 f32 迁移版的优化前后，末节另列旧整数引擎的直接对照。评分公式、两段截断、技能触发概率及延后模型均保持不变。后续候选存储优化及三版本同轮复测见 [候选存储与分组优化](scoring-candidate-storage.md)。

## 改动与证明范围

1. **恢复可证明的标量硬支配。** 设所有合法队伍的连续三维和不超过 M（当前使用最高单卡的五倍）。同一位置替换 A/B、其余成员不变时，连续差值为 A.stat − B.stat。两队原生累加偏差分别由既有 `linear_power_lower/upper` 包围。因此，差值至少为 `upper(M) − lower(M)`（再覆盖 f64 运算误差）时，无论其余成员和物理位置如何，A 的计分综合力都不低于 B。技能条件仍需成立。未超过此范围时继续要求逐维占优，不凭总和删除近似同分候选。
2. **按真实触发位置包围技能覆盖。** 最长时长序列提供每次触发的最晚结束，最早开始不早于该技能键。以二者包围所有可能窗口并取并集，包含单次与连锁延后。第一段截断预算逐键按实际 Fever 倍率计算；只有并集内的按键预留额外技能放大与第二段截断损失。浮点 gamma 预算未缩减。
3. **共享等价摆放数据。** 只有原有第一段整数键分等价证明成立时，才复用静态 120 项索引和可达掩码。需要按最低综合力筛选摆放时采用写时复制，不修改共享表；非等价分组仍保留独立布局。
4. **控分展示。** 结果注明按从左到右的顺序配置队伍；五张卡共用横向摆放网格，序号的无障碍标签为摆放位置，避免误解为技能触发顺序。

## 验证

- 新增近似同分不能走标量硬支配、明显优势跨三维分布在全部 120 种摆放仍占优的回归。
- 新增手动/Auto、无延后/单次延后/连锁延后的 4,374 组时长序列，逐键检查实际技能覆盖在包围范围内，并核验取整损失不超过预算。
- 核心 244 项通过，原有 1 项忽略；包括完整小卡池穷举与生产剪枝结果对照。
- 数据层 28 项、三队求解器 23 项、WASM 接口 10 项通过；加上核心共 305 项通过，保留原有 11 项忽略。
- 前端 178 项通过；控分提示已使用实际结果渲染器与卡牌组件检查默认宽屏及 390px 窄屏。
- 已重建网页 WASM，10 组实际 WASM 与原生输出对照通过，覆盖控分、单曲/巡回最高分及平均 PT、协力、Auto 和技能延后。运行时资源标识更新为 `native-f32-2`。

主要差距仍集中在候选构建及相关准备。原始候选比旧版多约 6.8%～11.7%；最终三队候选已经很接近旧版。1456 平均 PT 的第二队检查从 1,193,604,480 到 1,196,068,789，第三队检查从 19,784,531,363 到 19,760,261,009；最高分两组的 exactWork 分别仅增加约 0.05%、0.06%。因此三队搜索单轮耗时的上下变化不代表检查工作量大幅改变。

剩余候选构建成本包含原生浮点评分、摆放相关的综合力分组和安全上下界等迁移成本；不能只凭此阶段总时间断言某一个内部函数贡献了全部差距。后续优化应继续细分这一阶段，不通过恢复旧算术或放宽正确性边界来追平时间。

八份输出分别与对应版本的既有输出逐字段核对一致（仅排除 `metrics`、`solver`）。新旧版之间最高分仍分别是 10,781,643 → 10,781,591、11,815,764 → 11,815,694，属于算术修正；本轮没有新增评分变动。当前版与迁移初版保持相同结果。
