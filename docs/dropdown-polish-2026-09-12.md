# 下拉框统一优化与验收（2026-09-12）

预览入口：`http://127.0.0.1:8093/?design=30#activity`。

## 实现

- 在 `src/ui/select.js` 统一增强单选下拉框，保留原生 select 的值、表单校验与 input/change 事件，继续使用现有业务逻辑；不引入第三方依赖。
- 超过 8 个可见选项时提供搜索；活动支持名称和 ID 搜索，精确 ID 优先。短列表直接选择，长名称允许换行。
- 统一细边框、选中勾号、悬停、焦点与禁用状态。窄屏增大触控高度，兼顾减少动态效果和系统高对比度设置。
- 支持方向键、Home/End、PageUp/PageDown、Enter、Tab、Esc 和短列表字符定位。搜索框保留文字编辑和输入法操作。
- 使用 Popover 顶层展示，避免被弹窗或滚动区域裁剪；根据可用空间向上或向下展开，并约束在可视区域内。旧 WebView 不支持时保留原生控件。
- 选项变动、条件字段重建、禁用状态和页面切换统一更新；Esc 只关闭下拉列表，保留父弹窗。

交互参考：[WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)；顶层展示参考：[MDN Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)。
