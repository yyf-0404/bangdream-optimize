# 自定义卡牌接入与本轮修复

## 自定义卡牌

- 采用已确认的独立列表及编辑器；游戏卡牌与自定义卡牌分开管理，指定队伍中也分开筛选。简略和详细信息仍使用共享卡牌组件。
- 当前档案保存 `customCards` 和 `nextCustomCardId`。每张卡有 UID、启用状态、完整 `CardDefinition`、养成数据及编辑器资料。
- ID 从 1000000001 开始，最大 1999999999；界面显示 C-001。复制分配新 UID/ID，删除不回收编号。导入同 UID 更新，冲突的新卡重分配 ID，不覆盖历史编号。
- 默认三维表示 0 突破、满级特训后且剧情全开；突破单独计算。可选高级设置保留等级三维、特训及剧情加值。
- 同乐队、同属性条件可独立选择“不限制”；两项均不限制时使用条件触发后的加成。
- 编辑器只允许现有引擎支持的技能时长。递增技能固定起始 100%，每个 PERFECT +0.5%，上限 150%，时长限 5/5.5/6/6.5/7 秒。没有扩展 DP/谱面技能计算算法。
- 禁用卡保留资料但不进入计算；指定队伍引用禁用卡会报错并定位到队伍区。原生与 WASM 共用卡牌合并和校验，不请求 Bestdori 的自定义卡号。
- 新档案没有配置区域道具时，自动组队可使用零加成。指定队伍的选定道具组仍要求有效等级。
- 结果保留提交时的自定义卡资料，之后修改或删除卡牌不改变历史结果。
- 含自定义卡的 Base64 配置使用可扩展 v3 gzip 格式；普通档案仍沿用 v2。旧版不能读取 v3，避免静默丢卡。

## 本轮界面修复

- 最高得分的预设活动、类型筛选和自定义类型均限制为挑战、竞演、巡回演出。切换计算目标后保留原配置；若类型不兼容，显示提示并阻止计算。
- 前端校验保留目标字段/区域，切换到对应页面、滚动、聚焦、显示错误说明与高亮。已实际检查控分 PT、活动类型、指定队伍禁用卡、区域道具零级四条路径。
- 档案详情使用明确的渐变主按钮“切换到此档案”，已实际切换并切回测试档案。
- 移除旧的 JSON“复制结果”入口及仅适用于最高得分的数据转换代码。头图操作区增加“保存结果图片”，将结果主体生成 PNG 并复制到剪贴板；可查看图片，写入失败时提供重试/下载。
- 浏览器使用 ClipboardItem 的 Promise 保留点击时的用户激活；桌面端通过 Tauri clipboard-manager 写入原生图片。
- 修复诊断弹窗导出后无明显反馈的问题，并延迟回收下载 Blob URL，避免浏览器下载尚未开始就失效。保留完整诊断 JSON 和原生保存对话框。
- 初始化完成前禁用计算按钮，防止脚本未绑定时触发原生 GET 表单提交。

## Bestdori 道具映射

核对官方 Team Builder 加载的公开脚本：
- https://bestdori.com/js/app.d390adb1.js
- https://bestdori.com/js/ToolTeamBuilder.6367a448.js

属性顺序为 Powerful / Cool / Happy / Pure。

| 来源字段 | 正确道具 ID |
| --- | --- |
| Plaza（广场） | 70 / 66 / 67 / 69 |
| Menu（食物） | 56 / 57 / 58 / 60 |

原映射将两组对调且使用了错误的属性顺序。本次同时修复导入和导出，补上每项等级均不同的回归用例。Bestdori 的 null 表示未配置，0 表示 1 级，现可双向保留。允许导入空卡牌的合法 Bestdori 配置。

按实际道具 ID 保存的 JSON、Base64 以及主乐队公开资料不交换等级。已经错误导入并保存过的档案无法与手工修改可靠区分，未自动交换所有现有数据；应使用原始 Bestdori 配置重新导入并核对变更。

## 图片代理与部署

Bestdori 图片没有允许截图读取的跨域响应头。结果截图复用 `/bestdori/header/` 的固定来源代理，新增白名单内的乐队/属性/稀有度图标、卡牌缩略图、歌曲封面与区域道具图片。限制固定域名、路径、类型、4 MiB 单图、超时和缓存容量；SVG 响应使用隔离 CSP。开发预览和 Rust 后端同步规则。

本轮更新需同时发布前端、WASM、后端；桌面端需要重新构建。已配置 `location ^~ /bestdori/header/` 的生产环境不需要新增 Nginx 路由。

截图库按需加载本地 html-to-image 1.11.13，保留 MIT 许可证，没有新增在线脚本依赖。

## 自定义卡牌紧凑布局与单一技能时长

- 列表收紧至宽屏约 95px 行高；编号、属性与稀有度同排，操作按钮并排。窄屏按内容宽度换行，保留完整三维、技能与操作。
- 编辑器收紧预览栏、字段间距与区块留白，卡牌名称和角色同排，所属乐队移至标题旁。技能只设一组加成与时长，不再提供技能等级或各等级时长。
- 时长使用数字输入框，失焦就地校验，错误提示列出支持值；保存时阻止无效输入。切换技能模板时保留时长，按新模板重验，递增技能仍固定从 100% 开始。
- 存储和引擎协议不变：新保存的固定时长复制至五个时长槽，内部技能等级固定 5。读取原有自定义卡牌时取其已选技能等级的实际时长，再编辑不会自动换成最高等级时长。
- 队伍及结果的自定义简略信息用秒数替代 Lv.，详情去掉技能等级；普通游戏卡牌继续保留技能等级。
- 119 项前端测试通过，新增旧数据有效时长保留、空值/非法时长/模板切换校验用例。浏览器验证 6.1 秒阻止保存、7.5 秒切换递增后报错、6.5 秒保存回读。独立浏览器检查 1280/960/390px 页面和编辑器均无水平溢出。

- 时长上下箭头和键盘方向键统一按支持列表切换相邻档位，不再使用浏览器默认 ±1。非档位输入按方向找到最近的支持值，到达边界停止；递增技能使用自己的时长列表。12 项自定义卡牌测试通过，浏览器实际验证鼠标、键盘、非档位输入和边界。

- 技能分区与基本信息、三维与突破共用 field-section 样式：取消专属渐变底、负边距和额外内边距，统一标题与分区细线；技能模板采用相同的上方标签排版。时长档位交互保持不变。
