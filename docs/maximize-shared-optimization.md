# 最高得分复用三队搜索优化（2026-09-16）

最高得分现已接入平均 PT 使用的两项优化：第二队 AVX2 批量过滤 / 第三队前缀复用，以及卡牌兼容性 / 另外两队合计分数上界剪枝。此前已共用的候选压缩评分、技能顺序种子缓存、固定规模分配和支配覆盖剪枝保持不变。

后续已将这两个组合拆成四项，完成新旧档案单独开启及逐项关闭的 42 次完整对照，见 [四项优化拆分测试](maximize-four-way-ablation.md)。下文保留接入时的原始测量，勿与后续批次混算耗时。

## 同条件前后对照

同一台 Windows 机器，Rust 1.93.1，原生 Release，单线程精准搜索 `StrictExact`。两种模式使用同一个可执行文件，通过实验开关切换。本表的“之前”是 v0.4.3 已有优化全部保留、仅关闭本轮两项新增接入，不是旧的等概率技能模型。

- 新档案：1456 卡，国服活动 323；活动曲按 186 SP / 395 SP / 772 EX 排列。
- 旧档案：1414 卡历史 fixture；自定义活动 0，306 EX 三曲。
- 每种情况各两轮，无单独预热；交错执行：新关 → 新开 → 旧开 → 旧关 → 新开 → 新关 → 旧关 → 旧开。
- 计时运行之间没有并发计算、编译或测试。计时日志和候选指纹的开销在两种模式中都保留。
- 此处不允许自动切换随机桶。实际各池候选规模也未超过自动精准搜索阈值 196608。

## 共用实现与边界

- `crates/core/src/medley/disjoint_bound.rs` 从平均 PT 私有目录移至共用目录。两种目标调用同一个受内存预算约束的兼容性上界实现，最高分使用整数门槛 `current_best + 1`，不套用平均 PT 的 18500 分区间。
- `crates/medley-solver/src/reuse_band.rs` 提供共用的第二队批量过滤和第三队兼容前缀扫描；`reuse_max.rs` 只适配最高分的稳定排序、严格门槛和最优结果回调。扫描器的同分遍历顺序与原最高分扫描一致。
- 原生 AVX2 支持 1–4 个 `u64` 的专门化掩码；更宽的掩码沿用已有正确路径。WebAssembly 与无 AVX2 目标保留标量扫描，仍能使用共用的兼容性剪枝；本报告不是浏览器 WASM 性能结果。
- 按剪枝前候选数量判断 Auto 的精准 / 随机桶路径。显式随机桶、快速近似，以及本来超出 Auto 精准阈值的池，保留其候选序列和原有路径。
- 显式候选 API 使用实际冲突掩码而非展示卡牌 ID 推导兼容关系。空掩码、超过五个资源的通用输入保留原路径。
- 上界查询的预算截断会使用未检查尾部的最高分，不会把未检查当成无解。

## 验证与复现

- core 194 项有效用例通过（包括定向复测）；1 项原有压力测试忽略。
- medley-solver 23 项通过，2 项原有性能测试忽略。
- 576 组扫描对照覆盖 1 / 2 / 3 / 4 / 5 / 7 字掩码、空池、空掩码、同分、尾部不足四条及动态门槛，核对原扫描 / 标量 / 共用扫描的最高分和队伍索引。
- 共用剪枝保留原有穷举合法三队、受限索引和稀疏卡牌位置测试；新增最高分严格门槛、实际掩码、通用输入回退和 Auto 阈值边界测试。
- WASM core 编译通过，仅保留原有未使用代码警告。
- 12 次完整档案运行均通过业务结果与原始候选指纹核对。

同一二进制的对比功能由 core 的 `experimental-maximize-optimizations` feature 启用，它同时开启 solver 的测试开关：

```text
BANGDREAM_OPTIMIZE_MAXIMIZE_REUSE=off/on
BANGDREAM_OPTIMIZE_MAXIMIZE_COMPATIBLE_PRUNE=off/on
```

普通生产构建不读取这两个实验开关，默认启用优化。平均 PT 的实验开关与行为保留。

本地复现文件在 `tmp/maximize-shared-study/`：`harness/`、`run.py`、`analyze.py`、每轮结果与日志、`*-run.json`、`analysis.json`、`source-hashes.json` 和 `environment.json`。输入和二进制 SHA-256 均保存在每轮元数据中；该目录及用户档案不提交。

```powershell
cargo build --release --offline -j 1 --manifest-path tmp/maximize-shared-study/harness/Cargo.toml --target-dir target
python -X utf8 tmp/maximize-shared-study/run.py
python -X utf8 tmp/maximize-shared-study/run.py --ablation
python -X utf8 tmp/maximize-shared-study/analyze.py
```

运行脚本跳过已完整结束的轮次；重新计时应使用新的输出目录。
