    新增组件规范

    1. 先找现成的：能用上面的基础组件组合出来，就不写新样式。
    2. 需要新样式时，颜色、字号、间距、圆角、阴影、时长只用 var(--…) 设计变量；test/design-system.test.js 会拦下新 CSS 里的固定色值和时长。
    3. 真正通用的新组件放进 src/design/components.css，类名用 .ui- 前缀，并在本页加一个示例（测试会检查）。只属于某个页面的样式放在该页面目录下，例如 src/pages/result/。
    4. 组件里的文字加 .ui-text 类，不要依赖裸的 p、h3 标签：旧页面样式会按页面给它们不同的颜色和间距。
    5. 状态用原生属性表达（disabled、aria-pressed、aria-selected…），不要新增 .is-active 一类的类名。
    6. 动效只用 motion.css 的模式或 --motion-* 变量，不单独写时长；减少动态效果的处理随变量自动生效。
    7. 改完在本页和对应页面各看一遍；改动旧页面样式时，用 scripts/design/ui-snapshot.mjs 比较修改前后的截图和计算样式。
